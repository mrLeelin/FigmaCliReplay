# 顶部 Bridge 版本徽标设计

## 目标

在插件顶部发布版本徽标右侧常驻显示 Unity Bridge 版本，让用户无需等待版本错误即可看到当前 Bridge 状态。

## 展示规则

- 未连接 Unity、主动断开或切换工程后：灰色 `Bridge --`。
- Unity 健康检查成功且版本一致：绿色 `Bridge <实际版本>`。
- Bridge 版本与插件发布版本不一致：红色 `Bridge <实际版本>`。
- Bridge 未报告版本：红色 `Bridge 未报告`。

顶部现有插件版本徽标保持不变，新徽标紧邻其右侧，不合并两个版本文本。

## 数据流

不新增 Companion 或 Unity 接口。版本数据继续来自 Unity `/health` 响应的 `version` 字段：

1. 页面初始化为 `Bridge --`。
2. `probeUnityUrl` 读取并比较 Bridge 版本。
3. 匹配成功时更新为绿色实际版本。
4. 不匹配或缺失时，在抛出既有版本错误前更新为红色实际值或“未报告”。
5. 断开、开始新的连接或切换工程时重置为 `Bridge --`，避免显示旧工程版本。

## 错误处理

顶部徽标只是现有版本校验状态的可视化，不改变连接拦截规则。版本不一致仍然阻止 Unity 连接，设置页继续显示错误，“同步 Bridge”按钮继续可用。

## 测试

- 静态 UI 测试验证徽标位于插件版本右侧。
- 可执行状态测试验证未连接、匹配、不匹配和未报告四种显示状态。
- 全量 Node 测试、TypeScript 构建和类型检查保持通过。
