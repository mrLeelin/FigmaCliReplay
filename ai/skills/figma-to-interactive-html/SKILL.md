# Figma 交互动态展示

## 从模板开始

1. 优先复用已有的分层清单、透明资源、文字和业务层级。需要读取在线 Figma 时，使用项目的 `figma-relay` 技能定位指定文件和节点。
2. 将 [通用 HTML 模板](assets/interactive-ui-template.html) 复制到交付位置，默认命名为 `index.html`。通过 HTML 内的 `preview-config` 填入该界面的布局与交互。
3. 按源稿的尺寸、比例和叠放摆放资源。保留透明度和可编辑的 DOM 文本，使用可离线使用的字体。核对替代字体的字宽、描边和可读性。

## 配置界面

| 字段 | 填法 |
| --- | --- |
| `scene` | 设置画板宽高、背景、名称与 `autoOpen`。画板会等比适配视口。 |
| `assets` | 按名称注册内嵌的 `data:image/...` 资源。图片层用 `asset` 引用对应名称。 |
| `layers` | 从底到顶排列图层。支持 `group`、`image`、`text`、`shape`、`button`。`x/y/w/h` 使用相对父层的设计像素，组内图层写入 `children`。 |
| `motion` | `enter` 与 `exit` 控制整屏进退。图层的 `enter` 可配置错峰入场，`loop` 控制独立的待机循环。时长和延迟以毫秒填写。 |
| `state` 和 `actions` | `state` 存放演示初值，文字用 `{{变量}}` 引用。按钮通过 `action` 引用动作。动作可包含单个目标图层的动效、状态更新（`set` 或 `add`）、面板（`title` 和 `body`）。 |

源稿里的图形按钮可用业务组容纳图片和文字，在组里放置同范围的透明按钮并设置 `label`。点击区域跟随要动的组。逐个为可操作控件接入可见反馈，缺少业务数据时使用可复现的本地演示规则。

## 扩展具体动作

配置优先。需要多段编排或源稿有长按提示时，补充该动作的事件与动画，沿用模板的进退和取消机制。

- 入场结束后才进入待机，关掉界面时停止循环，重开后恢复一次。
- 主要按钮动作应有明确的触发、反馈和提交时点。按动作定义处理连点；有长按时同时处理松手、取消和退出。
- 退出可打断入场或正在运行的动作。从当前画面接续离场，结束后隐藏界面并显示重开入口。退出后使本轮动画、定时器和未提交的回调失效。
- 整屏进退、局部循环和点击反馈作用于各自的容器。减少动态效果模式仍须完成状态转换与按钮操作。

## 验收和交付

在真实浏览器打开最终文件。核对画面、素材和文字，逐个点击控件；实测入场、循环、快速连点、退出打断及重开。适合触控的界面使用手机视口并验证触控命中。若自动化入口限制 `file://`，用本机临时服务测交互，再用浏览器本地文件模式检查直接打开，并核对离线运行。

交付 HTML 文件与打开方式，简述实测范围及演示数据、字体替代等影响。
